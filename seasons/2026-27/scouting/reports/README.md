# 球探報告版本檔案

正式路徑：`reports/<player-slug>/YYYY-MM-DD.v1.md`。同一天新版本用 `v2`、`v3`，**永不無聲覆寫**；每次改版說明差異。由 `../report-template.md` 起稿，全部使用繁體中文。

`watchlist.json` 是會更新的待辦，不是球探報告證據；`reports/` 是研究快照，不是 rosters 或 ownership 權威。

狀態嚴格區分：`BLOCKED` / `PROVISIONAL`（內容資料不足）、`REVIEW_READY`（內容驗收可供審閱）、`PR_PENDING`（GitHub branch/PR 已讀回）、`ARCHIVED`（合併後從 GitHub main 讀回）。`PR_PENDING` 是寫入狀態，不能取代報告內容狀態；正式發布前兩者要分別交代。

如本資料夾只有此說明，表示**尚無完成的球探報告**；不應把排隊個案算成已研究完成。
